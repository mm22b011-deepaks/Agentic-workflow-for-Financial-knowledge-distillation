# index-earnings-nowcast

Index-level earnings nowcast from corporate earnings documents. Free OpenRouter models do
the extraction; every derived metric (surprise, growth, beat rate) is computed in code.
Outputs are index-level only: no ticker or CIK ever reaches `reports/` or `aggregates/`.

> **Status (2026-10-31).** Phases 0–3 and 2B are built and green: config, paths, logging,
> manifests, the LLM layer, EDGAR/local ingestion, the S&P 500 universe builder and the
> extraction runner. Aggregation, nowcast, evaluation and reporting (phases 4–8) are not
> built yet. See `status.md` and `tasks.md`.

## 15-minute Colab quickstart

1. Open `notebooks/00_colab_bootstrap.ipynb` in Colab.
2. Edit the parameter cell: `REPO_URL` and `BRANCH` for your copy of this repository.
3. Add two Colab secrets (the key icon in the left sidebar):
   - `OPENROUTER_API_KEY` — an OpenRouter key. Only `:free` models are used, so a free key
     is enough.
   - `SEC_USER_AGENT` — `your-app-name you@example.com`. The SEC requires a contact.
4. Mount Drive when prompted. The notebook sets `DATA_DIR` to `<Drive>/nowcast-data`, so the
   download cache, raw documents and extractions survive a session restart.
5. Run all cells. The notebook only calls the CLI; there is no business logic in it.

```bash
# What the notebook runs, if you prefer a terminal:
pip install -e '.[dev]'
python -m nowcast.cli validate-config --strict
python -m nowcast.cli build-constituents
python -m nowcast.cli ingest --set data.constituents_csv=data/universe/constituents.csv
python -m nowcast.cli extract --limit 10
```

`ingest` is capped by `data.edgar_max_documents` (default 100) and
`data.edgar_docs_per_cik` (default 3). It never bulk-scrapes EDGAR.

## Expected input files

All paths are relative to the data root unless absolute. A missing optional file is fine
until the stage that needs it runs.

### `constituents.csv` (required for ingest)

Point-in-time index membership. An empty `effective_to` means "still a member".

| ticker | cik | effective_from | effective_to | weight |
| --- | --- | --- | --- | --- |
| AAPL | 0000320193 | 1982-11-30 | | 1.0 |
| XYZ  | 0001234567 | 2019-06-01 | 2023-03-17 | 1.0 |
| XYZ  | 0001234567 | 2024-01-02 | | 1.0 |

`weight` is optional (defaults to 1.0). A ticker with two non-overlapping rows is a
company that left and rejoined the index; that is expected, not an error. Overlapping rows
for the *same* company fail the build.

Build it rather than hand-writing it:

```bash
python -m nowcast.cli build-constituents
# -> data/universe/constituents.csv, + build_report.json, member_count_audit.csv,
#    anomalies.csv, unmapped.csv
```

### `local_manifest.csv` (optional; documents you supply yourself)

| document_id | cik | report_date | document_type | path | source |
| --- | --- | --- | --- | --- | --- |
| doc-001 | 0000320193 | 2025-01-30 | 8-K-EX99 | files/doc-001.htm | local |
| doc-002 | 0000789019 | 2025-01-29 | 8-K-EX99 | files/doc-002.htm | local |
| doc-003 | 0001234567 | 2025-02-04 | 10-Q | files/doc-003.htm | local |

`path` may be absolute, relative to the manifest, or relative to the working directory.
Files are copied into `data/raw/<cik>/<document_id>/` and hashed.

### `labels.csv` (optional; needed by evaluation)

| document_id | field | true_value |
| --- | --- | --- |
| doc-001 | reported_eps | 2.40 |
| doc-001 | guidance_direction | raised |
| doc-002 | revenue | 124300000000 |

Labels are hand-written, never generated by the model. A missing file or column is an
error naming the expected schema; the pipeline never invents labels.

### `consensus.csv` (optional; the consensus baseline)

| fiscal_year | fiscal_quarter | target | value |
| --- | --- | --- | --- |
| 2025 | 1 | beat_rate | 0.62 |
| 2025 | 1 | eps_growth_agg | 0.081 |
| 2025 | 2 | guidance_ratio | 0.55 |

### `weights.csv` (optional; only with `aggregation.weighting: market_cap`)

| ticker | weight |
| --- | --- |
| AAPL | 0.071 |
| MSFT | 0.065 |
| XYZ | 0.004 |

Weights are validated on load and must be positive; they are renormalised over members
active on each date. With the default `equal` weighting this file is not read.

## Configuration

`configs/config.yaml` is the single source of truth. Override any key from the command
line with repeated `--set key.path=value`; `DATA_DIR` in the environment overrides
`paths.data_dir`. Secrets come only from the environment, never from the YAML.

| Key | Default | What it does |
| --- | --- | --- |
| `paths.data_dir` | `data` | Root for every runtime folder. `DATA_DIR` wins. |
| `data.start_date` / `data.end_date` | `2025-01-01` / `2026-10-31` | Download window. Ingest raises if neither is set instead of using today's date. |
| `data.constituents_csv` | `inputs/constituents.csv` | Point-in-time membership file. |
| `data.edgar_max_documents` | `100` | Hard cap on downloads for one run. |
| `data.edgar_docs_per_cik` | `3` | Per-company cap, so one prolific filer cannot fill the budget. |
| `data.sec_user_agent_env` | `SEC_USER_AGENT` | Name of the env var holding the SEC contact string. |
| `data.sec_max_requests_per_sec` | `8.0` | Client-side rate limit for SEC requests. |
| `llm.models` | two `:free` ids | Every entry must end in `:free`; a paid id fails validation. |
| `extraction.max_repairs` | `2` | Repair turns after an unparseable reply. |
| `budget.max_usd` | `0.05` | Spend cap. Free models cost $0, so this is a guard, not a limit you hit. |
| `extraction.min_confidence` | `0.5` | Records below this go to the review queue. |
| `extraction.quote_match_min_ratio` | `0.85` | How closely an evidence quote must match the source text. |
| `extraction.themes` | 6 themes | One `<theme>_share` column each in the aggregates. |
| `universe.source` | `wikipedia_changes` | or `historical_csv`. See *Known limits*. |
| `universe.min_cik_coverage` | `0.98` | Build fails below this membership-day coverage. |
| `universe.member_count_tolerance` | `8` | Audit band around `expected_members`. |
| `runtime.max_concurrency` | `4` | Concurrent LLM calls. |
| `runtime.log_level` | `INFO` | Logging level. |

Run `python -m nowcast.cli validate-config --strict` before any real run: it names a
missing environment variable without ever printing its value.

## Resume and caching

- Every stage writes a manifest to `data/manifests/<stage>.manifest.json`: config hash, git
  sha, Python and package versions, prompt hashes and input fingerprints. Two runs with the
  same config hash and input fingerprints did the same work.
- `build-constituents` is idempotent: unchanged config and unchanged input hashes make no
  HTTP requests.
- LLM replies are cached on disk under `data/.cache/llm`, keyed on model, temperature,
  max tokens and the prompt digest. Only successfully parsed replies are cached, so a
  crash mid-parse retries rather than replaying a bad answer. Disable with
  `--set cache.enabled=false`.
- Extraction is resumable per document: already-extracted documents for the same
  fingerprint are skipped, so `extract` after a crash continues from where it stopped.
- Nothing is written outside `DATA_DIR`, so pointing `DATA_DIR` at Drive makes a Colab
  session restart cheap.

## Troubleshooting

| Symptom | Cause and fix |
| --- | --- |
| `environment variable OPENROUTER_API_KEY is not set` | Add the key to the environment or to `.env` in the project root (`cp .env.example .env`). In Colab, add it as a secret — the notebook copies secrets into the environment. |
| `environment variable SEC_USER_AGENT is not set` | Set it to `app-name contact@example.com`. The SEC rejects requests without a contact. |
| HTTP 403 from SEC | Same as above: a missing or generic User-Agent. Also check `data.sec_max_requests_per_sec` — the SEC asks for stays under 10/s. |
| `BudgetExceeded` / run stops mid-way | `budget.max_usd` was reached (only possible if a paid model were configured; free models cost $0). Raise it deliberately, or leave it as a guard. |
| `model ... is not a free model` | A model id without `:free` reached config or code. Remove it — paid models are never used for extraction. |
| `constituents file not found` | Run `build-constituents`, or pass `--set data.constituents_csv=<path>`. |
| `could not locate the changes table` | Wikipedia changed its table layout. The error lists the columns actually found; update the aliases in `wikipedia_source.py` or switch to `universe.source: historical_csv`. |
| CIK coverage below threshold | A delisted or renamed ticker is unmapped. Review `data/universe/unmapped.csv` and add rows to `inputs/cik_overrides.csv` (columns `ticker,cik`). |

## Universe: known limits

These are real characteristics of the data sources, not bugs to silence:

1. **The changes log starts in 1976.** Members added before that (and still present) have
   no recorded addition date. They are written to `anomalies.csv` as `unknown_start` and
   excluded from `constituents.csv`, so historical coverage before 1976 is incomplete by
   construction. Every date from 2025 onward is unaffected.
2. **Ticker changes are recorded as a remove plus an add.** When a company changes ticker
   (FLT→CPAY, RE→EG, UA→UA-C) the log names a ticker that was never separately added; those
   appear as `remove_missing`. The membership itself is correct.
3. **Corporate renames look like name mismatches.** "KKR" vs "KKR & Co.", "Google" vs
   "Alphabet Inc." are the same company. Legal suffixes, punctuation and containment are
   normalised before comparing, which reduced `name_mismatch` from 62 to 10; the residual
   ten are genuine renames (Avago→Broadcom, FMC Technologies→TechnipFMC) and are recorded,
   not corrected.
4. **"Date added" on the current table and the event date can differ.** Announcement and
   close dates differ by days. The event log is authoritative; a gap over 30 days is
   recorded as `start_conflict`. Five such rows exist (WTW, HWM, IQV, GOOGL, NWSA).
5. **CIks come from the SEC's *current* ticker map**, so delisted companies (ATVI, ALXN,
   ABMD, AKS, …) are unmapped: 74 tickers, coverage 0.991. Coverage is weighted by
   membership-days, and the build fails below `universe.min_cik_coverage`.
6. **Index membership is approximated**, not licensed. The reconstruction reproduces a
   member count of 493–504 over 2025–2026 against a nominal 500 (all within tolerance),
   but it is not S&P's own historical file. Replacing it with a licensed file is a config
   change (`universe.source: historical_csv`), not a code change.
7. **A ticker can name two companies.** Reuse is handled with a per-ticker stack, and
   same-company overlaps fail the build while different-company overlaps are recorded as
   an anomaly — but a build is only as good as the two Wikipedia tables agree.

## Layout

```
configs/config.yaml          all settings
prompts/extraction/v1/       system + user templates, few-shot pairs
src/nowcast/
  config.py paths.py logging_setup.py manifest.py errors.py cli.py
  llm/          caller, cache, ledger, prompts, structured
  ingestion/    constituents, edgar, local_adapter, doc_index, universe/*
  parsing/      html, sections
  extraction/   schema, validators, runner, review_queue
tests/unit, tests/fixtures
scripts/        one-off probes and sample runs (not imported by the package)
```

Runtime folders under `data/` (all git-ignored): `raw/` (documents, plus `raw/universe/`
source snapshots), `extractions/`, `manifests/`, `universe/`, `.cache/llm/`; `aggregates/`,
`nowcasts/` and `reports/` appear with the later phases.
