# ADR 005: deterministic local checks, separate online verification

make check and the synthetic demo must run after bootstrap with no secrets and no network access. Dependency advisories and external-link verification inherently consult changing remote services, so they are separate online CI jobs. The offline gate never treats a network failure as a passing audit.

Pandas aggregation remains the current computation. Outputs are equal-weight company-growth proxies, not index-provider earnings. The independent synthetic recompute reads corpus truth and observed field exclusions, not the aggregator's intermediate values. It compares exact values using the same explicit sum/count arithmetic to avoid differing floating summation algorithms.

Jobs and quota reservations use SQLite/SQLAlchemy with an Alembic revision. The broader historical facts/hierarchy migration, nowcasting and evaluation remain planned, and are not implied by the presence of this database.
