# 011 — CLI canvas and index KPI knowledge base

Accepted 2026-11-02.

Generate the canvas command and flag catalogue from argparse. A JSON extension supplies icon, layout, binding and sub-node metadata. CLI, API workers and standalone phases share the same services. Runtime configuration values are served separately so a private local overlay cannot change the built registry. Inspector execution checks unchanged, server-owned upstream artifact fingerprints again under the worker lock.

The human clarified the final knowledge base contains index proxies only. Its closed schema retains KPI, season, as-of date, value, unit, observations, denominator, coverage, status and artifact hashes. Suppressed values remain null. Company facts, source text and human verdicts remain private inspection inputs, never knowledge-base exports. RAPTOR and XBRL stay visibly planned because neither hierarchy/retrieval implementation has been verified; there is no claim that a RAPTOR hierarchy exists.

Use the requested React Flow, Zustand, Motion, Dagre, Recharts, Virtual and Tailwind libraries. TypeScript 7 exceeded the current typescript-eslint supported peer range, so pin TypeScript 6.0.3. Pin the patched minimatch transitively to remove the dependency audit finding; verify installation, lint and browser behavior instead of suppressing the advisory. Native systemd verification caught that WorkingDirectory does not strip quotes; retain raw absolute directory text and quoted ExecStart arguments.

Text limits apply to the visible active view, counting letters and numeric tokens and excluding expanded Help answers. Inspector tables, schema fields, diff fields and CLI controls page their visible content. Evidence shows a short source-row excerpt; the complete source remains available through the private evidence API, without exports or replay inclusion. This bounds density while retaining row/period validation against the full source.

The graph file is a closed layout-and-edge document, without artifact payloads, parameters, labels or identifiers. It cannot introduce shell commands, uploaded code or planned-stage execution. Run all retains the canonical CLI stage order; step execution uses the selected command and validated upstream artifacts.

The canvas has a compact production graph and stage/maintenance/demo groups to keep every CLI command available within the visible-word limit. Inspector controls show two at a time; artifact tables use a virtual row and server pagination. Full-frame schema summaries are computed before paging. Current and frozen-run evidence use the extraction settings effective at execution. Per-record and per-field verdicts are private inputs, excluded from every export/replay.

Coverage gate markers divide the unchanged minimum observation count by each cell's eligible denominator; a count threshold is never plotted as a percentage. Quality colours use measured field/KPI coverage, with unavailable stages hollow. Cost colours use measured durations; the limiter ring uses persisted requests. Edge loss is shown only where both stage input/output counts are comparable.

The pinned Playwright browser is installed in executable RAM storage for this space-constrained ARM64 host. Browser test artifacts stay under ignored data/screenshots and test-results; they are never packaged. Bootstrap/fresh-source acceptance may reuse host tool/dependency caches and must report that limit.

Real-release presence takes precedence over synthetic demo output even before any KPI can be published. A failing real-API/browser probe and integration regression caught this fallback defect. Polling has a single in-flight refresh so a slow artifact read cannot start overlapping refresh storms. Accessibility checks cover panels, Help and charts as well as the canvas; auxiliary filter controls are outside the tablist and dialog containers use valid elements.

Imported graphs preserve edited edges and hidden-node restoration within one known command group; mixed-group imports are rejected. Contextual Help selects the page containing the requested question while preserving manual paging/search. A browser selector also needed to allow the visible expansion glyph in the accessible name.
